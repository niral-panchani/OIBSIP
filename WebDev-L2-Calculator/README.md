# Calculator Web Application

## About
A simple browser-based calculator built using HTML, CSS, and vanilla JavaScript. It supports basic arithmetic operations through an interactive button interface.

## Features
- Addition, subtraction, multiplication, and division
- Decimal number support
- Clear and delete buttons
- Sequential operator calculations
- Division-by-zero error handling
- Responsive layout using CSS Grid

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone the project.
2. Open `index.html` in a web browser.
3. Use the calculator buttons to perform calculations.

## Project Structure
- `index.html` — Calculator structure
- `style.css` — Styling and layout
- `script.js` — Calculator functionality
