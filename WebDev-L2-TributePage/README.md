# Tribute Page – Dr. A. P. J. Abdul Kalam

## About
A responsive tribute webpage dedicated to Dr. A. P. J. Abdul Kalam, an Indian aerospace scientist and former President of India.

## Features
- Biography section
- Portrait image
- Timeline of key achievements
- Inspirational quote section
- Responsive layout for mobile and desktop
- Smooth navigation between sections

## Technologies Used
- HTML5
- CSS3

## How to Run
1. Download the project files.
2. Keep `index.html`, `style.css`, and `kalam.jpg` in the same folder.
3. Open `index.html` in a web browser.
