# To-Do Web App

## About
A simple task management application built with HTML, CSS, and vanilla JavaScript. Users can organise tasks into pending and completed lists.

## Features
- Add, edit, complete, and delete tasks
- Separate pending and completed task lists
- Live task counters and empty-state messages
- Task creation and completion timestamps
- Automatic saving with browser localStorage
- Responsive layout for desktop and mobile

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser localStorage

## How to Run
1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Open `index.html` in a web browser.
3. Add tasks and manage them using the available buttons.

## Storage
Tasks are stored locally in the current browser. They are not synced between browsers or devices.
